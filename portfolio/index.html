Chapter 01

The Path So Far

I started with voice commands and if-else logic. Realized I needed LLMs. Built an AI. Then built an OS around her. Then a CNC machine controlled from Telegram. Each project was a question I needed to answer by building.

2020 — 2024

Exploring everything. Committing to nothing yet.

33 certifications across Python, C, networking, management, design. HTML in 2023, SQL in 2023, prompt engineering in 2024. It looked like wandering — it was actually surveying the map before choosing a mountain.

2025

The shape of what I actually want.

18 more certificates — but this time aimed: networking fundamentals, Linux security, cybersecurity foundations, IoT (both with honors), Arduino. The collection became a curriculum.

2026 — Present

The actual work begins.

Industrial training at BSRM. AI-powered data analysis (Star Performer). Books, communities, real projects: an OS, a browser in C++, a window manager, a file manager, a CNC plotter. The certificates stopped being the point — the building became the point.
